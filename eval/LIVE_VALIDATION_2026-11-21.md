모델 단독 비교는 잘못된 사실과 고칠 구절만 출력한다. 참인 문장의 확인 능력은 이 실험으로 비교할 수 없다. 규칙 번호가 어긋난 3건 중 ‘trade services는 무역 서비스의 가격’이라는 문장이 두 번 등장했고 모두 사실 불일치 경로로 표시됐다. ‘현재 기업의 12%가 AI를 쓴다(2023년 조사)’에는 기대한 R12 대신 R02가 붙었다. ‘연준의 물가 목표는 PCE 물가 상승률 기준 연 2%다’는 기대한 확인 판정을 받지 못했다.

## 공식 수치로 확인한 오판

별도 입력은 “미국 노동통계국(BLS)이 발표한 2026년 7월 미국 소비자물가지수(CPI)는 전년 동월 대비 3.4% 상승했다”였다. BLS가 공표한 비계절조정 전년비는 3.4%다. Redline은 계절조정 계열 CPIAUCSL의 332.813과 322.169로 3.3039%를 계산해 ‘불일치’로 표시하고 **3.3%로 수정**하라고 제안했다. 제품 코드와 실험 정답 생성기가 같은 계산 함수를 써서 16편 평가에서는 이 문제가 드러나지 않는다. 공식 헤드라인 전년비는 CPIAUCNS, 계절조정 전월비는 CPIAUCSL로 연결하고 보도자료 수치를 회귀 테스트의 독립 정답으로 사용해야 한다. [BLS 7월 보도자료](https://www.bls.gov/news.release/archives/cpi_08122026.htm)

- Redline 16편 중앙값 25.4초, 평균 23.6초, 범위 10.8~35.1초. 짧은 실험 원고이고 세 편씩 병렬 실행했으며 통계 조회 캐시를 공유했다. 비교 모델 호출을 포함한 16편 실험 경과 시간은 220.6초다. 별도 CPI 원고의 검토 시간은 6.22초였다. 사용자의 결과 확인·교정 시간은 이 값에 포함되지 않는다.
- Redline 16편에서 모델 82회, 웹 검색 50회, 입력 83,058토큰, 출력 19,295토큰을 기록했다. 원자료로 판정한 주장 48건, 검색으로 판정한 주장 35건이다. 모델 단독은 16회, 별도 CPI 원고는 모델 2회·검색 0회였다.
- 공개 단가로 계산하면 Redline 16편의 사용료는 약 0.23달러, 편당 약 1.43센트다. 입력 토큰 전체에 비캐시 단가를 적용했다. 모델 단독 비교와 별도 CPI까지 포함한 추정 사용료는 약 0.30달러다. 실제 청구액과 크레딧은 조회하지 않았다. [Liner 요금표](https://liner.com/developers/docs/pricing)
