# Redline 데모 영상 대본 (초안)

- 길이: 약 4분 20초 (제한 5분)
- 형식: 화면 녹화 + 자막 + AI 목소리 해설. 해설 음성도 Liner API(음성 합성)로 만든다.
- 해설은 3인칭으로 쓴다(AI 목소리가 "저는"이라고 말하지 않게).
- 화면에 나오는 원고는 전부 시연용 가상 원고다. 회사 내부 자료·개인정보 없음.
- 해설 분량 약 1,500자 (견본 기준 초당 7자 안팎).

## 확인할 것

1. 장면 2의 경력 서술(25년, 컨설팅·증권사에서 보고서 검토)이 사실과 맞는지.
2. 장면 6의 "대표가 실제로 틀렸던 그 용어" — trade services 오역이 실제 있었던 일인지, 발행까지 됐는지.
3. 장면 2에 회사 홈페이지의 대표 소개 화면을 써도 되는지(사진 포함 여부).
4. 목소리: 여성 톤으로 결정(2026-11-20). "빨간" 발음이 부정확해 다른 여성 목소리 견본 C1(Leda)·C2(Aoede)·C3(Kore, 상위 모델)을 추가로 만들었다.
5. 장면 10의 한계 언급 — 영상에서는 짧게 넘어가고 기획서와 README에 자세히 적었다. 영상에도 한 줄 넣을지.
