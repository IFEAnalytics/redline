# Redline 출품 영상 대본

공개 통계로 만든 가상 원고를 실제 제품에 입력한다. 아래 해설은 한국어 합성 음성으로 읽고, 시연에서 긴 대기 구간은 편집한다. 표의 결과는 해당 실행에서 확인한 뒤 사용한다.

| 장면 | 화면 | 해설 |
|---|---|---|
| 발행 직전 | 검토 원고 입력, 리서치 묶음 선택, 검토 시작 | 컨설팅 회사와 증권사에서 보고서는 선임의 책상을 한 번 더 거칩니다. 일인 리서치 회사를 차리자 내 원고에 빨간 줄을 그어 줄 사람이 사라졌습니다. 레드라인에 칠월 미국 물가 원고를 맡겨 봅니다. |
| 틀린 숫자 | 2.9%로 적힌 근원 CPI 문장과 불일치 카드 확대 | 원고에는 근원 소비자물가가 이 점 구 퍼센트 올랐다고 적혀 있습니다. 라이너 모델이 지표와 비교 기간을 읽고, 레드라인은 일 년 간격의 두 지수를 가져와 다시 계산합니다. 고쳐 쓸 숫자는 이 점 오 퍼센트입니다. |
| 맞는 숫자 | 헤드라인 3.4% 확인 카드, FRED 계열과 계산식 | 바로 앞 문장의 삼 점 사 퍼센트는 그대로 둡니다. 미국 노동통계국이 전년 대비 상승률을 발표할 때 쓰는 비계절조정 계열과 일치합니다. 작성자는 계산식과 출처를 열어 확인할 수 있습니다. |
| 숫자 밖의 사실 | 트레이드 서비스 검색 결과 카드와 근거 구절 | 숫자로 풀 수 없는 문장도 있습니다. 생산자물가에서 트레이드 서비스는 국제 무역 비용을 뜻할까요? 라이너가 출처를 찾아 대조합니다. 이 지표가 측정하는 것은 도소매업자가 상품을 사고팔 때의 유통 마진입니다. |
| 제안서로 확장 | 같은 화면에서 제안서 규칙으로 변경, 기간 충돌 카드 | 다음은 컨설팅 제안서입니다. 본문에는 열두 주라고 썼지만 진단 네 주, 설계 여섯 주, 이행 지원 네 주를 더하면 열네 주입니다. 선임이 일정표를 볼 때 하던 질문도 검토 규칙에 담았습니다. |
| 검증과 사용 | 검토 결과와 실험 조건, 발행 결정 | 이전 버전에서 가상 원고 열여섯 편을 같은 모델로 비교했습니다. 원고만 읽힌 경우에는 심은 수치 오류 스물네 건을 놓쳤고, 통계 원자료와 대조한 경우에는 모두 찾았습니다. 작성자는 근거를 확인하고 원고를 고친 뒤 발행을 결정합니다. |
