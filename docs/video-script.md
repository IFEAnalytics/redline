# Redline 데모 영상 대본 (최종)

- 길이 약 3분 15초 (제한 5분). 화면 녹화 + 자막 + AI 목소리 해설.
- 해설 음성은 Liner Model API의 음성 합성(`google/gemini-2.5-flash-tts`, 목소리 Aoede)으로 만들었다.
- 검토 실행 장면은 실제 Liner API 호출을 그대로 녹화했다. 해설보다 오래 걸린 실행 구간만 빠르게 재생하고 화면 오른쪽 위에 배속을 표시했다.
- 화면의 원고는 전부 시연용 가상 원고다.
- 만드는 법: `tools/video/` (`tts.py` → `make.py`). 대본 원본은 `tools/video/script.json`.
